# Hardware

This directory is intended to hold the hardware documentation and project assets for Vikāsa. The current design is preliminary and should be treated as a planning document rather than a verified assembly guide.

## Scope

- Hardware notes and architecture references
- Sensing node layout and integration planning
- Circuit design resources and calibration considerations
- Field deployment and enclosure coordination

## Proposed hardware focus

The design is centered on non-invasive plant stress sensing using red and NIR reflectance measurements. Environmental sensing and signal conditioning are expected to support the optical measurements.

## Pending details

The following items are not final and require design review:

- Sensor arrangement and optical geometry
- Amplifier and filtering circuit selection
- Power architecture and wiring plan
- Enclosure and mounting concept
- Calibration and validation approach

## Status

No physical board, circuit, or enclosure has been validated in this repository. Any hardware decisions should be confirmed before deployment.

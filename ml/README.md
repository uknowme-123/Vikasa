# Machine Learning

This directory contains the proposed ML workflow for Vikāsa. It is structured to support future model development, validation, and export tasks.

## Planned subdirectories

- `data_validation/` — checks for completeness, ranges, and consistency
- `preprocessing/` — filtering, scaling, transformation, and cleaning logic
- `features/` — feature extraction and engineered dataset creation
- `training/` — model training scripts and experiment tracking
- `evaluation/` — metrics, diagnostics, and validation reporting
- `export/` — packaging and model export utilities
- `models/` — model artifacts and metadata

## Proposed model direction

The project intends to develop a lightweight model that connects reflectance and environmental observations with plant stress indicators. The exact target labels, feature set, and architecture remain open questions.

## Validation note

This folder describes a planned ML pipeline only. No trained model files, tested accuracy claims, or production inference results are included.

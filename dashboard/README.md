# Dashboard

This directory is reserved for the Vikāsa dashboard layer, which is intended to present plant health trends, sensor readings, and system status in a user-friendly interface.

## Proposed capabilities

- Visualize current and historical plant-condition readings
- Display reflectance and environmental trends
- Summarize device health and connectivity
- Highlight alarm or stress states for operators

## Planned role

The dashboard is expected to act as the primary human-facing interface for plant monitoring and operational awareness. It will consume data from the backend and may integrate with Firebase or direct REST endpoints.

## Pending decisions

- Dashboard framework and UI tooling
- Data refresh strategy and charting approach
- User roles and permissions
- Alert presentation and notification workflow

## Status

Dashboard implementation has not been designed or built in this repository yet.
